# Icone PWA

Questa cartella deve contenere le icone referenziate dal manifest
(`vite.config.ts`). Sono contenuti da produrre e approvare (sezione L del piano),
non ancora presenti nel repository:

- `icon-192.png` — 192×192
- `icon-512.png` — 512×512
- `icon-maskable-512.png` — 512×512, `purpose: maskable`

Fino a quando non vengono aggiunte, il manifest le referenzia ma il browser
userà il fallback. Generarle dal logo definitivo prima del lancio pubblico (M9).
